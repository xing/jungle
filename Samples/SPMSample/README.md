# SPMSample

A Swift Package Manager sample project demonstrating Jungle's analysis capabilities.

## Dependencies

This project includes popular Swift packages:
- **Alamofire** (5.8.0+) - HTTP networking library
- **RealmSwift** (10.45.0+) - Mobile database
- **SwiftyJSON** (5.0.0+) - JSON parsing library
- **Kingfisher** (7.10.0+) - Image downloading and caching

## Usage

Run Jungle to analyze module dependencies:

```bash
jungle modules --target SPMSample
```

## Building

```bash
swift build
```

## Testing

```bash
swift test
```
